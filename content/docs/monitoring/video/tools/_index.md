Use **Video Assist Tools** to compose a shot, check focus and exposure, preview color adjustments, and monitor stereoscopic material.

{{< screenshot name="assist-tools-all" alt="Video Assist Tools" >}}

## Choose a tool

| Task | Tools |
|---|---|
| Compose and align | [Composition Guides](/docs/monitoring/video/tools/composition-guides/), [Center Mark](/docs/monitoring/video/tools/center-mark/), [Safe Area](/docs/monitoring/video/tools/safe-area/), [Framing Guides](/docs/monitoring/video/tools/framing-guides/) |
| Correct image geometry | [Orientation](/docs/monitoring/video/tools/orientation/), [Anamorphic Desqueeze](/docs/monitoring/video/tools/desqueeze/) |
| Check focus and keying | [Focus Peaking](/docs/monitoring/video/tools/focus-peaking/), [Color Keyer](/docs/monitoring/video/tools/color-key/) |
| Evaluate exposure | [Zebras](/docs/monitoring/video/tools/zebras/), [False Color](/docs/monitoring/video/tools/false-color/), [Exposure](/docs/monitoring/video/tools/exposure/), [Spot Meter](/docs/monitoring/video/tools/spot-meter/) |
| Preview and inspect color | [Image Adjust](/docs/monitoring/video/tools/image-adjust/), [Display LUT](/docs/monitoring/video/tools/display-lut/), [Color Palette](/docs/monitoring/video/tools/color-palette/) |
| Monitor stereo material | [3D Preview](/docs/monitoring/video/tools/3d-preview/) |

Select a tool in the **Assist Toolbar** to turn it on or off. Open its options drawer to adjust it, and save your configuration in a [preset](/docs/customize/presets/).

Each tool page explains how to use it and lists its settings.

> You can combine tools. Start with the ones needed for your current check, then turn off overlays that make the image difficult to read.

## Tool option drawers

Long-press a tool button in the **Assist Toolbar** to open its options drawer, then long-press it again to close the drawer. On iPad, touch and hold; on Mac, press and hold the mouse or trackpad button.

{{< screenshot name="toolbar-button-slide" alt="Exposure options drawer above its Assist Toolbar button" caption="An options drawer opens above its tool button." max-width="555px" >}}

On Mac only, you can also select the small **chevron** beside the tool button. **View → Tool Settings** provides another way to open drawers on Mac or on iPad with a hardware keyboard.

Only one options drawer is open at a time. Opening a tool's drawer closes any other drawer that was open.
