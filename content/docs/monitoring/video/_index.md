## Start monitoring video

1. On **Home**, choose **Add Source → Camera** or **Media File** and add the device or file.
2. Select **Monitor** on its source card to display the picture. For a file, select **Play** on the transport bar.
3. Select a tool in the **Assist Toolbar**, or open **Scopes → Histogram** to check the signal. Composition grid guides and the Histogram are free.

See [Getting started](/docs/start-here/getting-started/) for a complete first session. To configure audio paired with a video source, see [Audio monitoring](/docs/monitoring/audio/).
